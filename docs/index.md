**torque-postgresql** is a plugin that enhances Ruby on Rails, enabling easy access to existing
PostgreSQL advanced resources, such as data types and query statements. Its features are designed
to be similar to Rails architecture and work as smoothly as possible.

Fully compatible with **schema.rb** and 100% plug-and-play, with optional configurations, so that
it can be adapted to your project's design pattern.
